# 🎂 ケーキやさんレジ（おままごと POS）

おままごとのケーキ屋さんで使う、iPad の Safari で動くレジアプリです。
インストール不要で、HTML / CSS / JavaScript だけの静的サイトです。

## できること

- ケーキを タッチして おかいものかごに入れる（ピッ♪）
- ＋ / − で こすうを かえる、ぜんぶ けす
- おかいけい：おもちゃのお金（10円〜10000円）を タッチして「おあずかり」、「ちょうど」ボタンもあり
- たりないと「ブブー」、たりると おつりを けいさん
- けってい で「ガシャ チーン♪」とレジの音、レシートが印刷されるアニメーション、紙ふぶき
- 「ごうけい ○○えん です」「ありがとうございました」と よみあげ（右上 🗣️ でオン/オフ）
- 右上 🔊 で こうかおん オン/オフ
- **せってい画面（おとな用）**：左上のお店の名前を **1.5びょう ながおし** すると開きます
  - 商品ごとの値段を変更（−100 / −10 / ＋10 / ＋100 ボタン、または数字を直接入力）
  - お店の名前を変更
  - 「ねだんを もとに もどす」で最初の値段に戻せます
  - 設定はその iPad（ブラウザ）の中に保存されます

効果音はすべて Web Audio API でその場で作っているので、音声ファイルは不要です。
iOS はタップするまで音が出せないため、最初に「おみせを あける」ボタンを押す画面があります。

## 商品を かえる・イラストに する

`app.js` の先頭の `PRODUCTS` を編集します。

```js
{ id: 'shortcake', name: 'ショートケーキ', emoji: '🍰', price: 300, img: '' },
```

`img` に `'images/shortcake.png'` のように書くと、絵文字の代わりにイラストが表示されます。

## iPad で つかう（公開方法）

### A. GitHub Pages（おすすめ）

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 1〜2分後に `https://ztbtlab.github.io/MamagotoPosSystem/` で開けます

> ⚠️ リポジトリが **非公開（private）** の場合、GitHub Pages は GitHub Pro / Team などの有料プランが必要です。
> 無料プランなら、リポジトリを公開（Settings → General → Danger Zone → Change visibility）にするか、下の B を使ってください。

### B. Netlify Drop（アカウント作成だけで無料・非公開リポジトリでもOK）

1. このリポジトリを ZIP でダウンロードして展開
2. https://app.netlify.com/drop にフォルダごとドラッグ＆ドロップ
3. 表示された URL を iPad で開く

### iPad の ホーム画面に 追加

Safari で開いて **共有ボタン → 「ホーム画面に追加」** すると、アプリのように全画面で使えます。
iPad の **消音（マナー）モードがオンだと音が出ない** ことがあるので、音が出ないときは確認してください。

### パソコンで ためす

`index.html` をブラウザで開くだけで動きます。
